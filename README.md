# BizFlow 360

BizFlow 360 is a business management application designed to help businesses manage their daily operations from one place.

## Features

- **Dashboard:** View important business statistics.
- **Product Management:** Organize and manage products.
- **Inventory Management:** Track stock levels and identify low-stock products.
- **Customer Management:** Manage customer information.
- **Order Management:** Create and manage customer orders.
- **Order Tracking:** Update order statuses from Pending to Delivered or Cancelled.
- **Business Settings:** Customize business details, currency, and inventory preferences.
- **Admin Account:** Manage administrator login credentials.
- **Printable Invoices:** Generate printable invoices for orders.

## Technology

- Python
- FastAPI
- SQLAlchemy
- HTML
- CSS
- JavaScript

## Purpose

BizFlow 360 aims to simplify business management by bringing products, inventory, customers, and orders together in one organized system.
